Python kurulumu içerisinde python.exe ve pythonw.exe olmak üzere iki temel çalıştırılabilir dosya bulunur. python.exe, Python programlarını komut satırı üzerinden çalıştırır ve gerektiğinde konsol penceresi gösterir. pythonw.exe ise konsol penceresi açmadan Python programlarını çalıştırmak için kullanılır.

IDLE aslında ayrı bir Python yorumlayıcısı değildir. Python dili kullanılarak geliştirilmiş bir grafiksel geliştirme ortamıdır ve çalışmak için Python yorumlayıcısından yararlanır. Masaüstündeki IDLE kısayoluna tıklandığında Windows, kısayolda belirtilen çalıştırma komutunu kullanarak uygun Python yorumlayıcısını başlatır. Daha sonra Python, IDLE'ın gerekli kodlarını yükler ve grafiksel IDLE penceresi açılır.

IDLE'ın temel dosyaları Python kurulum dizini içerisindeki Lib\idlelib klasöründe bulunur. Buradaki Python dosyaları IDLE'ın editör, Python Shell ve hata ayıklama gibi özelliklerini sağlar. IDLE'ın çalıştırılması sırasında idlelib paketi Python yorumlayıcısı tarafından yüklenir. Bu nedenle pythonw.exe IDLE'ın kendisi değil, IDLE'ın Python kodlarını çalıştıran ortam olarak düşünülebilir.

Python'un kurulum dizininde Lib, Scripts, DLLs, Include ve tcl gibi farklı klasörler bulunur. Lib, Python'un standart kütüphanelerini ve idlelib gibi paketleri içerir. Scripts, çeşitli komut satırı araçlarını; DLLs, Python'un kullandığı bazı derlenmiş bileşenleri; Include, özellikle C/C++ geliştirmelerinde kullanılan başlık dosyalarını içerir. tcl klasörü ise özellikle Tkinter ve dolayısıyla IDLE'ın grafiksel arayüzü için kullanılan Tcl/Tk bileşenleriyle ilişkilidir.

Sonuç olarak IDLE, python.exe veya pythonw.exe gibi bağımsız bir yorumlayıcı değildir. IDLE'ın Python kodları Lib\idlelib içerisinde bulunur ve bu kodlar Python yorumlayıcısı tarafından çalıştırılır. Masaüstündeki kısayol da bu işlemi otomatik olarak başlatır. Böylece Windows, Python yorumlayıcısını çalıştırır. Python da IDLE'ın gerekli modüllerini yükleyerek grafiksel geliştirme ortamını oluşturur.
